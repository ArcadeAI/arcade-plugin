# Arcade docs entry points

When the question is about Arcade but is not a connected-app job and not a
production-rollout decision, read Arcade docs. Do not invent product behavior.

Docs pages return markdown to agents (known agent User-Agent, or
`Accept: text/markdown`). Start from the index, then open only the matching
page. Cite the page you used. Do not scrape the whole site.

- Index: https://docs.arcade.dev/llms.txt
- Home: https://docs.arcade.dev/en/home
- Build (call tools, MCP servers, agents, SDKs): https://docs.arcade.dev/en/build
- Operate (identity, gateways, audit): https://docs.arcade.dev/en/operate
- Agent quickstart: https://docs.arcade.dev/en/get-started/quickstarts/call-tool-agent
- Operator quickstart: https://docs.arcade.dev/en/operate/quickstart
- Dashboard (configure there; do not claim a control from docs): https://app.arcade.dev
